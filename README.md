# PC Hub

パソコン部のPCを一覧・管理するダッシュボード（PWA）。データは使用するiPadのブラウザ内（IndexedDB）に保存されます。

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作成（例: `pc-hub`）。Public推奨（無料プランのPagesはPublicのみ）。
2. このフォルダの中身を**そのまま**（`index.html` がリポジトリ直下に来るように）アップロード。
   - Web画面の「Add file → Upload files」で、`index.html` `style.css` `app.js` `manifest.webmanifest` `sw.js` `icons/` フォルダをドラッグ＆ドロップ。
3. リポジトリの **Settings → Pages** を開く。
4. **Source: Deploy from a branch**、Branch: `main` / `/ (root)` を選んで Save。
5. 1〜2分後、`https://（ユーザー名）.github.io/pc-hub/` で公開されます。

## iPadでアプリとして使う

1. **Safari**で上のURLを開く。
2. 共有ボタン → **ホーム画面に追加**。
3. ホーム画面のアイコンから起動すると全画面アプリとして動きます（オフラインでも起動可）。

## 注意

- **データはiPadごとに別々**です。画面右上「設定」→「書き出し (JSON)」で定期的にバックアップしてください。別のiPadへは「読み込み」で移せます。
- Safariで「ホーム画面に追加」した版と、Safariのタブで開いた版はデータが別になります。**必ずホーム画面のアプリ側で入力**してください。
- 公開URLを知っていれば誰でも画面は開けますが、データ自体はそれぞれの端末内にしかないため、PC情報がネット上に公開されることはありません。
- ファイルを更新したときは `sw.js` の `VERSION`（`pc-hub-v1` → `pc-hub-v2` など）を変えると、iPad側にも新しい版が反映されます。

## メーカーロゴについて

メーカーのロゴ画像は同梱していません。「設定」→「メーカーロゴ」で、公式サイト等から入手した画像（PNG/JPG/SVG）をLenovo・Dell・HPそれぞれに設定すると、カードにロゴが表示されます。未設定の間はメーカー名の文字で表示されます。
