# PC Hub v4

パソコン部のPCを一覧・管理するダッシュボード（PWA）。Material 3 Expressive 風デザイン + Material Symbols アイコン。
データは使用するiPadのブラウザ内（IndexedDB）に保存されます。

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作成（例: `pc-hub`）。
2. このフォルダの中身を**そのまま**（`index.html` が直下に来るように）アップロード。
   （前のバージョンを置いているリポジトリなら、同じファイル名で上書きでOK）
3. **Settings → Pages** → Source: *Deploy from a branch* / Branch: `main` `/ (root)` → Save。
4. 1〜2分後、`https://（ユーザー名）.github.io/pc-hub/` で公開されます。

## iPadでアプリとして使う

1. **Safari**で公開URLを開く → 共有ボタン → **ホーム画面に追加**。
2. ホーム画面のアイコンから起動すると全画面アプリとして動きます。
3. 初回はオンラインで開いてください（アイコン・日本語フォントを読み込んで保存します。以後はオフラインでも表示されます）。

## v1 からのアップデート

- 前のバージョンで入力したデータは、そのまま引き継がれます（同じ公開URL・同じホーム画面アプリの場合）。
- 念のため更新前に、旧版で「設定 → 書き出し (JSON)」をしておくと安心です。
- 更新が反映されないときは、アプリを完全に終了して開き直してください。

## 主な機能

- **一覧**: カード／リスト表示、検索（ソフト名・タグ・借りている人も対象）、メーカー・OS・状態・タグ・お気に入りで絞り込み、並べ替え、場所別／メーカー別／OS別／状態別のグループ表示
- **選択モード**: 複数台をまとめて「状態変更・場所変更・点検済み・削除（元に戻せます）」、2〜4台の**スペック比較**
- **棚卸し**: 場所ごとに現物を1台ずつチェック。進捗リング、途中再開、未確認PCの記録と履歴
- **貸出管理**: 借りる人（過去の名前を候補表示）・返却予定日・期限超過の警告、貸出回数
- **点検・保証**: 最終点検日、保証期限、履歴にメモを追記
- **分析**: OS・メーカー・メモリ・ストレージ・導入年・場所・タグ・ソフト・購入金額、機材コンディション、更新のおすすめ（Windows 11 対応の目安つき）
- **CSV読み込み**: 「CSVの雛形」をExcelで編集して一括登録。書き出したCSVを編集して再読み込みも可能（同じ管理番号は上書き）
- **共有して保存**: iPadの共有シートから「ファイル」やAirDropにバックアップを保存
- **いま使っているPCから読み取る**: PCのブラウザで開き、登録フォームのボタンでOS・メモリ（目安）を自動入力
- **OSロゴ・メーカーロゴ**: 設定から画像を登録（Windows・Zorin OS・ChromeOS Flex など）。白い背景を自動で透明にする取り込み、ダークモードで白く表示する切り替えつき
- **やることリスト**: 「貸出・点検」画面や各PCの詳細から追加。完了チェック、PCとの紐づけ
- **ラベル印刷**: PC1台、または選択した複数台の管理ラベル（A4・2列）を印刷
- **写真の拡大表示**、カードの大きさ（小・中・大）、点検・保証のお知らせ基準を設定
- テーマ色6色 + ライト/ダーク、学校・部活名の表示、台帳の印刷、外付けキーボードのショートカット（`/` 検索、`n` 追加）

## 注意

- **データはiPadごとに別々**です。定期的に書き出し（JSON）でバックアップしてください。
- Safariのタブで開いた版と、ホーム画面のアプリ版ではデータが別です。**ホーム画面のアプリ側で入力**してください。
- メーカーのロゴ画像は同梱していません。「設定 → メーカーロゴ」で設定してください。
- ファイルを更新したときは `sw.js` の `VERSION` を変えると、iPadに新しい版が反映されます。
